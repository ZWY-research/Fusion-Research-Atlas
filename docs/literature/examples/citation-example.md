# FRA citation-format example

This is a bibliographic rendering example; it adds no scientific claim.

The existing Greenwald record is cited first [@paper-greenwald-2007].
The Angioni 2003 record comes next [@paper-angioni-2003], followed by
Angioni 2007 [@paper-angioni-2007]. Repeating Greenwald [@paper-greenwald-2007]
uses its original local number. Mordijck is not cited and must not enter References.

Literal syntax in code stays literal: `[@paper-angioni-2003]`.
